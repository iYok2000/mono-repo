# project_context/

Feature documentation in "reference card" format. Keep docs concise — AI reads these for context, not as tutorials.

## Format
Each file should have: **What** (1-2 lines), **Where** (file paths), **Routes/Schema** (tables), **Key constraints/behavior**.
No code examples unless truly essential. Use `TEMPLATE.md` for new features.

## Naming
- `kebab-case.md`
- Create only for features with complex logic or multi-component scope
